# SPARTACO SECURITY — Architecture Documentation

This directory contains technical documents and reference materials related to the **SPARTACO SECURITY** technology architecture, developed by **Ilver Villasmil**\.

SPARTACO SECURITY brings together distinct areas of security and mathematical technology, including **OM337** &#40;cryptographic engine&#41;, **UIS–OMEGA** &#40;mathematical engine&#41;, and **UIS–TANA** &#40;mathematical certification framework&#41;\.

The documents collected here provide architectural context, technical explanations, and supporting material for understanding these components and their relationship to the **SPARTACO Primality Auditor & Verifier**\.

**Architecture documentation is not the auditor itself\.** The public auditor independently checks compatible mathematical evidence and primality certificates; access to the proprietary engines is not required for verification\.
